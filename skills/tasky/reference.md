# Tasky command reference

Generated by `tasky reference`; do not edit by hand. Regenerate with `scripts/update-skill-reference.sh` after changing the CLI.

## `tasky`

```text
Track projects of any kind, their goals, and a DAG of tasks

Usage: tasky [OPTIONS] <COMMAND>

Commands:
  init     Create an empty database; refuses to overwrite one
  migrate  Apply pending schema migrations to an existing database
  ui       Open the graph viewer on this database; returns when the window closes
  project  Anything work is organized under; optionally tied to a repository
  goal     High-level goals within a project, each with an optional spec
  task     Units of work that form a dependency graph
  help     Print this message or the help of the given subcommand(s)

Options:
      --db <DB>
          Path to the SQLite database
          
          [env: TASKY_DB=]
          [default: $XDG_DATA_HOME/tasky/tasky.db]

      --json
          Emit compact machine-readable JSON (errors go to stderr as JSON too)

  -h, --help
          Print help

  -V, --version
          Print version

Projects are referenced by path, such as app or app/mobile, or by a unique prefix or suffix of their ID. Goals are referenced as PROJECT/SLUG, as a slug that is unique across projects, or by an ID fragment. Tasks are referenced by ID fragment.
```

## `tasky task`

```text
Units of work that form a dependency graph

Usage: tasky task [OPTIONS] <COMMAND>

Commands:
  add        Add a todo task to a goal
  title      Replace the title
  body       Replace the body from --text, --file, or stdin
  test-plan  Replace the validation steps from --text, --file, or stdin
  pr         Record the pull request that delivers the task, or remove it with --clear
  list       List tasks, optionally filtered
  show       Show a task with readiness, dependencies, dependents, and links
  ready      Todo tasks whose dependencies are all done
  order      All tasks in dependency order, prerequisites first
  depend     Require `DEPENDS_ON` to be done before `TASK` can start
  undepend   Remove that requirement
  start      Move a ready task to in progress
  test       Hand an in-progress task over to validation against its test plan
  fail       Send a testing task back to in progress
  pass       Record that validation passed; the task is ready for merge
  done       Mark a task that is ready for merge done
  cancel     Cancel an open task
  link       Attach a commit SHA or URL
  help       Print this message or the help of the given subcommand(s)

Options:
      --db <DB>
          Path to the SQLite database
          
          [env: TASKY_DB=]
          [default: $XDG_DATA_HOME/tasky/tasky.db]

      --json
          Emit compact machine-readable JSON (errors go to stderr as JSON too)

  -h, --help
          Print help
```
